# CMT_project

## Project Description

This project aims to model and compare the activation of anthropogenic and natural aerosols into cloud droplets, and evaluate how their differing microphysical properties influence cloud albedo.
The workflow combines two open-source Python libraries:
Particula – to define and generate aerosol populations with realistic physical and chemical properties
Pyrcel – a 0-D cloud parcel model used to simulate aerosol activation and supersaturation dynamics
The final step computes cloud effective radius and albedo using classical microphysical approximations (Twomey effect). This enables quantification of the cloud radiative impact of different aerosol emissions.

## Objectives

1) Generate aerosol lognormal size distributions and hygroscopicity parameters for various aerosol types
(natural aerosols: sea salt and biogenic organic compounds; anthropogenic: sulfate, organic compounds and black carbon)
2) Simulate cloud activation using Pyrcel, producing:
* Maximum supersaturation Smax
​* Number of activated droplets Nd
​* Droplet radius evolution
3) Estimate:
* Cloud effective radius re
* Cloud albedo using a simplified radiative approximation
4) Compare outcomes for anthropogenic vs natural aerosol emissions and assess climatic impacts.

## Input files

The first category od input are the parameters of each aerosols: the hygroscopicity (kappa), the mean dry diameter (D_g_um or mu) in micron, the standard deviation (sigma_g).
For the general case, we chose a classic value for of number concentration per cm^3 (N0_cm3) of each aerosol in the atmosphere. For the case of sulfate, we made it vary around this value to observe the impact on the albedo. Thus, depending on this number concentration, we chose the number of bins (nb_bins) for the lognormal distribution. The number of bin was higher for a higher number concentration. Those values are the required to run each function. 
They are stored in the file aerosol_modes.csv thanks to aerosols_param.c. A class named AerosolMode is created to stored the values of the csv file for each aerosol.

The second category of input is the meteorological parameters. These values are optionnal parameters for the functions height_vs_raduis.py, logn_size_dist_compare_plot.py. For the base case, we chose: 
* Initial pressure: P = 77500.0 Pa
* Initial temperature: T = 274.0 K
* Initial supersaturation: S = -0.02 ie 98%. 

The third category contains the timescale and updraft speed. These are used to run the simulation of activation of aerosol packages into clouds droplet from Pyrcel and are optional parameters in height_vs_raduis.py. The values for the base case study are: 
* Updraft speed (m/s): V= 1.0 m/s
* End time: t_end= 250 s 
* Timestep: dt =1.0 s.

Finally the last catgory of input is the fitting parameters used to calculate the albedo in the C program: Albedo_fct.c. They are: 
* const double g = 0.85
* const double a = 2.0
* const double TWO_PI = 2.0 * 3.14159265358979323846
* const double MICRON_TO_M = 1e-6
* const double CM3_TO_M3 = 1e12;  // multiply cm^-3 by 1e6 to get m^-3
* the height of the cloud: h= 250 m

## Running the program

### Environment
Run in terminal: 
1) micromamba create -f environment.yml
2) micromamba activate pyrcel_quick_start

If the installation of the environment doesn't work, it is still possible to do it manually. 
To do so, please follow these steps:

1) Install Particula: `pip install particula` 
   [Particula scientific desciption](https://uncscode.github.io/particula/Theory/) 
2) Install Pyrcel: `pip install pyrcel`
   [Pyrcel scientific description](https://pyrcel.readthedocs.io/en/latest/sci_descr.html)
3) Other dependecies: `pip install numpy matplotlib scipy pandas os csv`


### Build

_Describe how the C program should be compiled (using gcc or mex). The executable or shared object file can be placed in the "bin/" directory._ 
To compile the C programs, use `gcc` to build the main workflow and the albedo function together. From the project root:
```
bash
gcc albedo_run.c Albedo_fn.c && ./a.out
```
### Execute

_Describe how the program should be executed. Ideally, it will be automated to one line of code in a terminal running Bash (e.g., matlab -batch src/myscript), with the outputs generated to "results/"._ 

Run: `./src/run_all.sh`

This will:
1. Generate aerosol populations
2. Run activation for each type
3. Compute droplet effective radius
4. Compute cloud albedo
5. Save results in "/results".
